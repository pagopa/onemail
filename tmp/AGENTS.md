# AGENTS.md - tmp

This folder is for local working material only.

## Purpose

- Use `tmp/` for temporary notes, draft reports, and user-specific artifacts.
- Files in this folder are not repository-facing deliverables.
- Files in this folder may use the user's preferred language, including Italian.

## Constraints

- Do not reference `tmp/` content from tracked source files, docs, workflows, or configuration.
- Do not move `tmp/` files into tracked repository paths without reviewing them against repository standards first.
- Keep work in this folder focused and disposable.

## Default behavior

- Prefer placing temporary analysis outputs here instead of under `docs/`.
- When the user asks for informal or local-only artifacts, default to `tmp/`.
